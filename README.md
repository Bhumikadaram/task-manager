# TaskFlow – Task Management System (React + Vite)

## Modules
- **Auth**: Signup / Login (localStorage)
- **User module**: create tasks, projects, deadlines, priority, deadline notifications, progress bar, mark complete, drag-and-drop Kanban board, share tasks with other users
- **Admin module**: stats, manage users, view/delete all tasks

Default admin: `admin@tms.com` / `admin123`

## Run
```
npm install
npm run dev
```
## Deploy
Push to GitHub → import the repo in Vercel (Framework: Vite) → Deploy.
